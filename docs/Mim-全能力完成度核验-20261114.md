## 二、线上状态：当前不可用（这是本轮最重要的发现）

2026-11-14 实测，`https://mim.mixm.top` 处于**部分损坏**状态，不能作为任何能力「已上线」的依据：

1. **TLS 证书域名不匹配**：443 握手返回证书 `CN=cloud.mixm.top`（Let's Encrypt YR2），与 `mim.mixm.top` 不符 → 浏览器与常规 HTTPS 客户端直接报证书错误，只能 `curl -k` 绕过。
2. **`/health` 已不再反代到后端**：`curl -k https://mim.mixm.top/health` → 200，但 body 是 SPA 的 `<!DOCTYPE html>`（含 `window.__MIXMAPP_API_BASE__="/mixmapp/api/v1"`），不是 JSON 健康检查。
3. **`/api/v1/*` 全量 404**：`/api/v1/health`、`/api/v1/search/summary`、`/api/v1/tools`、`/api/v1/security/status` 均返回本站自有错误信封
   `{"error":{"code":"NOT_FOUND","message":"未找到路由 GET /api/v1/xxx","requestId":"..."}}`
   → 有 mim-api 进程痕迹，但路由未挂载，或 nginx 反代指错上游。
4. **HTTP 80 也不通**：`http://mim.mixm.top/health` → nginx 1.18.0 (Ubuntu) 404 页。
5. **CI 部署已连续失败**：`Deploy` run `43461016173`(5baf204)、`43456958516`(6f0d73c) 的「发布到生产服务器」作业 failure，最新 `43462765667`(f441dbb) 仍在跑，其失败点已定位为 scp「上传本次提交的部署脚本」——主机 SSH 公钥被拒。
6. **本机无主机 SSH 私钥、无云控制台（tccli）凭证**，无法登录主机改 nginx 配置 / 重签证书 / 重启 mim-api。

**由此产生的影响**：仓库里 25 项「已完成」均为「代码 + 本地测试闭环」，**曾**在 `2db1e15` 那版部署上验证过线上 200，但当前生产不再是那版可用状态，需要一次成功的部署才能恢复。

## 四、必须优先处理的 5 个问题

1. **P0 · 生产不可用**：证书域名错、`/health` 不反代、`/api/v1/*` 全 404、CI scp 被拒。需要**主机 SSH 私钥或云控制台权限**（二者缺一不可修复）。这是当前唯一阻断「全部能力上线」的问题。
2. **P1 · 收银台缺失**：9 个支付渠道后端全通（含回调验签、幂等、退款），但 `apps/web` 里 `createIntent` **没有任何调用方**，没有二维码/跳转承接页。也就是说「支付能力」有引擎没方向盘——在线充值、VIP 开通、资产购买、订单支付，用户界面点不出来。
3. **P1 · 后台写入面缺口**：商品、优惠码、卡密、VIP 套餐**四类数据都没有后台 CRUD API**，只能写库或改种子。生产实测 `shop_products` 0 条，商城实际不可用。
4. **P1 · 三处口径不实**：Quick Build WP 不装宝塔；换域名不直连 MySQL；流盾 WAF 是正则规则集且未挂站点。对外描述需按代码事实修正。
5. **P2 · 配置文档与代码不一致**：极验/腾讯密钥名对不上、`.env.example` 漏登记 SSO/百度审核/CDN/Captcha 等 10+ 个变量。按样例填值会导致「以为配了其实没配」。

## 五、其余明确缺口（按域）

- 用户：手机号只有阿里云短信（腾讯云无适配器）；实名只有人工审核；等级是公式派生；IP 归属地只有国家码。
- 社区：圈子不支持付费入圈（无价格字段）；剧集无独立播放器页。
- 知识付费：免登录购买需先建访客会话、无数据接管；唤起支付宝未实现。
- 商城：网盘自动发货无字段；手动发货无履约单据。
- 营销：返佣只有一级首单 5%，无结算账户与周期；VIP 无按模块/分类定价。
- 交易：退货无回寄/验货流程；微信/支付宝 legacy 无上游退款。
- 运维：CDN 从未真实接入（只有契约+探测，判 `not-detected`）；Redis/Meili 无实例；「SQL 个位数」无统计证据。
- 外观：无后台可视化编辑器；`nav_layout` 切换不生效。
- 内容：推广曝光未实现。
