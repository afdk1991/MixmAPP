### 9.5 单文件入口迁移步骤与回滚

**迁移（多文件 → 单文件）**：

1. 干净 worktree 执行 `MIXMAPP_API_BASE=/mixmapp/api/v1 node scripts/build-h5-single.mjs`，产出 `release/mixmapp-h5-single.html`。
2. 备份现网：`cp -a /var/www/mixmapp-site /var/www/mixmapp-site.bak-<ts>`（多文件态另存 assets/static）。
3. 上传单文件覆盖 `/var/www/mixmapp-site/index.html`，确认 nginx `root` 指向 `/var/www/mixmapp-site`。
4. `nginx -t && systemctl reload nginx`。
5. 校验：`/` 返回 200 且体积约 372KB；`/mixmapp/api/v1/healthz` 200；深链接 `/pages/mall/index` 200；`/pages/tools/ids` 410。

**回滚**：恢复备份目录（单文件态恢复备份 index.html；多文件态整目录恢复 assets+static），`root` 指回原目录后 reload；API 侧沿用 `deploy/rollback.sh` 切回上一 release。

**反向（单文件 → 多文件）前提**：整目录替换 web/；assets 与 static 必须成对发布；index.html 不缓存；回滚需同时回退 web 目录与 current 软链。
