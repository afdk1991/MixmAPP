# MixmAPP 全站字阶统一（2026-11-13）

## 目标

解决 H5 / Android WebView 中小标签只有 8–10px、页面之间字号层级不统一的问题。只调整排版参数，不改业务逻辑、文案、接口和发号规则。

## 字阶

| Token | 值 | H5 约等于 | 用途 |
|---|---:|---:|---|
| `$fs-micro` | 24rpx | 12px | 等宽小标签、眉标、状态章 |
| `$fs-meta` | 28rpx | 14px | 说明文字、次级按钮、表单提示 |
| `$fs-body` | 32rpx | 16px | 正文、按钮、输入框 |
| 小标题 | 36rpx | 18px | 卡片标题、列表主标题 |
| 区块标题 | 40rpx | 20px | 页面内分区标题 |
| 大区块标题 | 44rpx | 22px | 强分区标题 |
| 强调标题 | 48rpx | 24px | 商品名、强标题 |
| `$fs-h1` | 56rpx | 28px | 页面标题 |
| 首屏标题 | 64rpx | 32px | 登录/注册/首屏主标题 |
| `$fs-display` | 84rpx | 42px | 首屏大标 |

## 规则

- 正文与控件不得小于 24rpx（H5 约 12px）。
- 页面级字号只允许落在 24 / 28 / 32 / 36 / 40 / 44 / 48 / 56 / 64 / 76 / 84rpx。
- 130 / 140rpx 的装饰性字标、`mx-logo` 标志内部比例保持原样，不参与正文缩放。
- 全局 `page` 行高统一为 `1.55`。
- 按钮、输入框改用 `$fs-body`，不再各自写 28rpx。

## 改动文件

- `apps/app/src/uni.scss`：字阶 token。
- `apps/app/src/App.vue`：全局行高。
- `apps/app/src/styles/theme.scss`：按钮、输入框字号改用 token。
- `apps/app/src/pages/`：首页、我的、登录、注册、商城列表、商品详情、购物车、订单、关于共 9 个页面，101 处显式字号归一。

## 验证

```bash
pnpm --filter @mixmapp/app typecheck
pnpm --filter @mixmapp/app build:h5
```

构建后需在 GitHub Pages 复核首页、「我的」、注册页、商城与订单页，确认无截断、无换行溢出。

## 边界

- 本轮不调整颜色、间距、圆角、阴影与栅格，只处理字号、行高和控件字级。
- iOS 原生壳与 Android 共用同一套 H5 产物，字阶随 H5 构建生效。
- 生产 `cloud.mixm.top` 的发布仍受服务器 SSH 凭据问题影响，与本次字阶改动无关。
