# MixmAPP 全站字体系统重设计（2026-11-13）

## 设计目标

上一版只做了“最小字号兜底”，页面之间仍然像同一套字号被逐处放大，缺少层级。这一版重做整套字体系统：先定义角色，再把页面收敛到同一组字号、字重、行高和字距。

原则：

- 先层级，后字号：大标、页标题、区块标题、正文、说明、标签各有固定角色。
- 正文优先：H5 与 Android WebView 的正文提升到 17px，说明 15px，最小标签 13px。
- 中文不压字：标题负字距从 -2rpx 收到 -1rpx，正文不再负字距。
- 数字等宽：编号、金额、日期统一 `tabular-nums`，避免跳动。
- 控件与正文同源：按钮、输入框使用正文字号，不再各自写一套。

## 字阶

| 角色 | Token / 值 | H5 约等于 | 用途 |
|---|---|---:|---|
| 标签 | `$fs-micro` 26rpx | 13px | 眉标、状态章、等宽小标签 |
| 说明 | `$fs-meta` 30rpx | 15px | 辅助说明、表单提示、次级按钮 |
| 正文 | `$fs-body` 34rpx | 17px | 正文、按钮、输入框 |
| 卡片标题 | `$fs-h3` 40rpx | 20px | 卡片/列表主标题 |
| 区块标题 | 44rpx | 22px | 页面内分区 |
| 强标题 | 48rpx | 24px | 商品名、强分区 |
| 次级页标题 | 56rpx | 28px | 模块页标题 |
| 页标题 | `$fs-h1` 68rpx | 34px | 页面主标题 |
| 首屏标题 | 84rpx | 42px | 移动端首屏 |
| 展示大标 | `$fs-display` 96rpx | 48px | 桌面/平板首屏 |

## 排版节奏

- 全局 `page` 行高 `1.7`；标题 `1.18`；区块标题 `1.25`；标签 `1.4`。
- 标题负字距 `-1rpx`，标签正字距 `3rpx`。
- 按钮高度 92rpx、次级按钮 72rpx；输入框 96rpx、文本域 176rpx。
- 标签高度 44rpx，印章内边距同步放大，避免文字顶边。
- `mono` 统一 `font-variant-numeric: tabular-nums` 与 `tnum`。

## 改动范围

- `apps/app/src/uni.scss`：重定义 10 级字阶与行高变量。
- `apps/app/src/App.vue`：全局行高 1.7。
- `apps/app/src/styles/theme.scss`：标题、标签、按钮、输入框、空态统一到新角色。
- `apps/app/src/pages/`：首页、我的、登录、注册、商城列表、商品详情、购物车、订单、关于共 9 个页面，123 处显式字号重新落位。
- `components/mx-logo/mx-logo.vue` 的标志内部比例、130/140rpx 装饰字标保持原样。

## 视觉检查点

- 首页大标在 720px 内容宽度内保持两行，不挤压副标题。
- 「我的」通行证编号、数字 ID、资料行不重叠、不被虚线切断。
- 注册页四个 Tab、表单标签、按钮在 375px 宽度下不换行溢出。
- 商城卡片标题、价格、库存说明层级清楚；订单页金额与状态不拥挤。
- 关于页版本号、能力矩阵标签保持等宽对齐。

## 验证

```bash
pnpm --filter @mixmapp/app typecheck
pnpm --filter @mixmapp/app build:h5
```

构建后复核 GitHub Pages 的首页、「我的」、注册页、商城与订单页。

## 边界

- 本轮只改字体系统与由字号带出的控件高度，不改颜色、间距体系、业务逻辑、文案、接口和发号规则。
- iOS 原生壳与 Android 共用同一套 H5 产物，字阶随 H5 构建生效。
- 生产 `cloud.mixm.top` 的发布仍受服务器 SSH 凭据问题影响，与本次字体重设计无关。
